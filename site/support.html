Start with the demo

Open the supplied Android project in Android Studio, build the debug variant and choose Explore synthetic demo. Sample entries are marked as synthetic and kept separate from live-user records.

No transactions after connecting Gmail?

This preview has no validated real-bank parser enabled. Connecting Gmail does not imply support for your bank. Unsupported messages are ignored. See the supported-format list included with the source.

Check delayed or missing data

Use Check emails now. Review the last successful email-check time separately from the last transaction received. Network limits, revoked authorization, Android scheduling and email delivery can delay updates.

Disconnect or erase

Settings → Disconnect collection stops new checks. Revoke access at Google opens your Google connections page. Delete local financial data removes this app user's transactions, budgets, goals and checkpoints; it does not delete Gmail messages or cloud authentication metadata.

A failed payment or missing refund

MoneyTrack cannot resolve bank-side failures or guarantee refunds. If the evidence does not include a failure cause, the app cannot confirm it. Use the support section of your bank's official app or website. This preview does not publish unverified bank phone numbers.

Project support

For this source preview, report issues through the repository where your maintainer distributes MoneyTrack. Remove account references, phone numbers, email content and transaction details before sharing an issue. A public support contact must be configured by the operator before launch.
